# Linux, Docker and Lightweight AI Learning Lab

[中文](README.md) · [Project plan and resource estimates](docs/project-plan.md) · [MIT License](LICENSE)

A non-commercial educational project for Chinese-speaking learners. It aims to publish free, reproducible learning materials about Linux, Docker, automation scripts and lightweight AI applications, including deployment, verification, troubleshooting and rollback.

## Current status

**Planning stage.** This repository currently contains the project description and an initial plan. It does not yet provide runnable tutorials, scripts or a public demonstration service. Resource requests are estimates, not benchmark results. No server sponsorship has been awarded.

The project draws on the maintainer's personal experience with Linux / Docker maintenance, automation scripts and local Ollama usage. That experience still needs to be documented and validated before it becomes a published project deliverable.

## Planned materials

- Linux and Docker deployment guides, service checks and troubleshooting examples.
- Automation scripts and configuration examples with verification and rollback instructions.
- Deployment notes, resource observations and limitations for small quantized models using Ollama.
- A small number of lightweight demonstrations when infrastructure permits.

The intended audience is beginners and individual developers learning server deployment, containers and lightweight AI tools. There are no established audience figures or validated performance claims.

## Getting started

Read the [project plan](docs/project-plan.md) for the proposed scope and infrastructure estimates. Questions, suggestions and contributions can be shared through this repository's Issues or Pull Requests. There is no software to install at this stage.

Each future example should document its environment, prerequisites, steps, verification results and cleanup or rollback procedure. Published materials must distinguish tested results from assumptions and must not contain credentials, private conversations or unauthorized data.

## Operating model and license

The project plans to provide free learning materials without selling goods or services, paid access, subscriptions or advertising revenue. Infrastructure support would be used for documentation, examples and validation environments. There is no confirmed sponsorship partnership.
