# Project guidance

- Keep the project focused on publicly accessible Linux, Docker, automation and lightweight AI learning materials.
- Separate planned work from implemented and verified examples. Do not invent users, benchmarks, sponsorships or affiliations.
- Record the environment and validation results for any runnable example. Preserve third-party license notices and exclude private data and credentials.
- Put extended documentation in `docs/`; append task outcomes, testing evidence, changed files and rollback instructions to `progress.md`.
