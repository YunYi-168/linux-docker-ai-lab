# Linux、Docker 与轻量 AI 实践共享计划

[English](README.en.md) · [项目规划与资源需求](docs/project-plan.md) · [MIT 许可](LICENSE)

面向中文学习者的非商业教育项目，计划免费公开 Linux、Docker、自动化脚本和轻量 AI 应用的实践资料，帮助读者理解部署、验证、排错和回滚过程。

## 当前状态

**筹备中。** 当前仓库提供项目介绍和初步规划，尚未发布可运行的教程、脚本或公共演示服务。资源需求为规划估算，尚未开展服务器性能测试，也未获得服务器赞助。

项目方向来自维护者已有的 Linux / Docker 部署维护、脚本自动化和本地 Ollama 使用实践。这些个人实践仍需整理与验证，不能视为本仓库已经交付的成果。

## 计划公开的内容

- Linux 和 Docker 的部署、运行状态检查及常见故障排查教程。
- 配套自动化脚本、配置示例，以及明确的验证和回滚说明。
- Ollama 小型量化模型的部署记录、资源占用观察和使用限制。
- 在资源允许时提供少量轻量演示，帮助读者理解示例效果。

资料面向学习服务器部署、容器和轻量 AI 工具的初学者及个人开发者。项目不预设用户规模，也不承诺未经验证的性能。

## 从哪里开始

目前可以阅读[项目规划](docs/project-plan.md)，了解首批内容范围与资源估算。已有实际问题、文档建议或愿意参与整理的内容，可以通过本仓库的 Issues 或 Pull Requests 提出；本阶段没有安装步骤。

后续发布的每个实践示例应说明运行环境、前置条件、操作步骤、验证结果和清理或回滚方法，并区分已验证结论与待验证假设。公开内容不包含个人凭据、私聊记录或其他未获授权的数据。

## 非商业运营与许可

项目计划免费提供学习资料，不销售商品或服务，不设置付费访问、订阅或广告变现。基础设施支持将用于项目文档、示例和验证环境；当前没有已确认的赞助合作。
